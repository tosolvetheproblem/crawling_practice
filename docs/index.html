크롤링할 때 지켜야 할 것


    

  • robots.txt 확인: 사이트 주소 뒤에 /robots.txt를 붙여 열어 봅니다. Disallow: /이면 자동 수집을 원하지 않는다는 뜻입니다.
    • 

  • 이용약관 확인: 데이터 수집이나 재사용을 금지하는 사이트가 있습니다.
    • 

  • 천천히 요청: time.sleep()으로 요청 사이에 간격을 둡니다.
    • 

  • 차단되면 멈춤: 403, 429 응답은 그만 요청하라는 신호입니다.
    • 







왜 이 연습 사이트인가


books.toscrape.com은 robots.txt가 없고(404) 연습용으로 공개되어 있습니다.


반면 네이버 부동산처럼 robots.txt에 Disallow: /를 둔 사이트는 자동 수집을 막고 있으므로 학습 대상에서 뺐습니다.
